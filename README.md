# AI-Second-Brain
A PHP AI app which can be used as a second brain. Here you can easily record ideas, thoughts and feelings. Automatically get a summary at the end of each day. Talk to an LLM in the app about your life and anything.

Uses OpenRouter.

Fully configurable.

---

This is a quickly done vibe coded app made as a personal tool rather than a public thing so it may not be that good.
The current auth system is not the best. It is recommended you change it.
